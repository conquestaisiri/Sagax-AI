# Support

For help with Sagax AI 1.5.8:

1. Read the [Getting started guide](docs/GETTING_STARTED.md).
2. Check [Troubleshooting](docs/TROUBLESHOOTING.md).
3. If the problem continues, open a [GitHub issue](https://github.com/conquestaisiri/Sagax-AI/issues).

Please include the Sagax version, Windows version, active mode, what you did,
and what happened. Do not post API keys, passwords, private interview audio or
transcripts, or screenshots containing sensitive information. This public
repository does not publish the application source code, so code contributions
to the desktop app cannot be reviewed here.
