# Security policy

## Report a vulnerability privately

Please do not post security vulnerabilities in a public issue. Use GitHub's
**Report a vulnerability** option on this repository's Security page so the
report is private.

Include the affected Sagax version, Windows version, the steps needed to
reproduce the issue, and its likely impact. Do not include real API keys,
passwords, private transcripts, or other people's personal information.

## Scope

This repository contains product information and release downloads. The
application source code is not published here. For a non-security problem,
please use [Support](SUPPORT.md) or open a normal issue.
