# Contributing

This public repository contains Sagax AI product information, user guides, and
release downloads. It does not contain the Windows application's source code.

You can help by reporting a clear bug, suggesting an improvement, or fixing a
documentation typo. For an app problem, use the issue forms and include the
version, Windows version, mode, and steps to reproduce. Never include keys,
passwords, private audio, or private interview content.

Changes to the proprietary application itself cannot be contributed through
this repository. See [LICENSE](LICENSE) for the terms that apply here.
